# 원본 배치를 보존하는 변환

새로 올린 PDF는 실제 용지 크기(A4/B4 등)를 읽고, 사진은 가로 210mm와 원본 종횡비를 사용한다. 인식 단계에서 문항의 인쇄 줄, 조건 상자, 각 선택지, 페이지 테두리·구분선의 좌표를 저장한다. 머리말과 안내·꼬리말은 인쇄된 문장을 읽어 한글에서 수정할 수 있는 글자로 넣는다. 이미지로 잘라 붙이지 않는다.

원본 좌표에 여유가 있는 경우 HWPX에서 한 쪽마다 별도 구역을 만들고 글과 수식을 편집 가능한 표에 배치한다. 조건은 테두리가 있는 별도 표로 유지하고 가로 선택지의 좌표를 보존한다. 글과 그림의 위치가 겹치거나 용지를 벗어날 위험이 있으면 글자와 그림이 밀리지 않도록 전체 시험지를 문단 흐름으로 다시 배치하고 화면에 알린다. 이 경우 원본과 쪽 구성은 달라질 수 있으므로 실제 한글 화면에서 확인한다. 조건 상자와 선택지 그림을 보존하고, 선택지와 그림의 대응이 불분명하면 임의로 번호를 정하지 않고 확인이 필요하다고 알린다.

한 문항의 그림이 여러 개면 모두 읽은 결과에 저장하고 각각 출력한다. 이전에 저장된 시험지에서 프로그램이 이미 버린 추가 그림은 기존 데이터만으로 복구할 수 없다. 완료된 시험지도 보관함에서 AI를 다시 호출하지 않고 저장된 결과로 한글 파일을 다시 만들 수 있다. 옛 머리말은 저장된 제목과 안내 글을 활용하되 원본과 비교가 필요하다고 알린다.

도형은 수학 명령으로 다시 그린다. 원본의 그림 영역을 기준으로 크기를 정하고, 글·선택지·다른 그림에 닿지 않는 빈 공간에서만 최대 1.4배 확대한다. 인쇄 글자 크기를 약 10pt 이상으로 맞추며, 선·다른 글자와 겹치는지 검사해 가까운 빈 곳으로 옮긴다. 각도 이름은 다른 각으로 이동하지 않도록 같은 이등분선 방향을 유지한다. 복잡한 그림에서 겹침이 남으면 경고한다.

검사는 AI 호출 없이 타입 검사, 빌드, 머리말의 편집 가능성, 복수 그림 보존, 겹침 시 조건 상자와 선택지 보존, 6쪽·그림 30개의 저장과 한글 출력까지 수행한다. 한글 프로그램의 실제 렌더링과 새 AI 인식 결과는 별도로 확인해야 한다.
