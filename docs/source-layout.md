# 원본 배치를 보존하는 변환

새로 올린 PDF는 실제 용지 크기(A4/B4 등)를 읽고, 사진은 가로 210mm와 원본 종횡비를 사용한다. 인식 단계에서 문항의 인쇄 줄, 조건 상자, 각 선택지, 페이지 테두리·구분선의 좌표를 추가로 저장한다.

HWPX에서는 원본 한 쪽마다 구역 하나를 만들고, 글과 수식은 페이지 좌표에 고정된 편집 가능한 표 안에 넣는다. 조건은 테두리가 있는 별도 표로 유지한다. 선택지는 원본의 좌표에 놓여 가로 선택지가 세로 목록으로 바뀌지 않는다. 머리말·결재란·문항 밖 안내·꼬리말은 원본 영역 이미지로 유지한다.

도형은 수학 명령으로 다시 그린다. 원본의 그림 영역을 기준으로 크기를 정하고, 글과 선택지에 닿지 않는 빈 공간에서만 최대 1.4배 확대한다. 인쇄 글자 크기를 약 10pt 이상으로 맞추며, 선·다른 글자와 겹치는지 검사해 가까운 빈 곳으로 옮긴다. 각도 이름은 다른 각으로 이동하지 않도록 같은 이등분선 방향을 유지한다. 복잡한 그림에서 겹침이 남으면 경고한다. 지도·사진·표는 기존처럼 원본 영역을 보존한다.

이전 보관함 자료에는 세부 배치 좌표가 없으므로 다시 변환해야 새 배치를 온전히 적용할 수 있다. 모델의 좌표 인식과 한글 글꼴·렌더링에 오차가 있어 원본과 픽셀 단위로 같음을 보장하지 않는다. 부족한 영역을 경고하고, 기존 자료를 자동으로 덮어쓰지 않는다.

검사: `npm run typecheck`, `npm run build`, `node scripts/run-ts.mjs scripts/check_layout_quality.ts`, `python scripts/check_source_hwpx.py`, `python scripts/check_hwpx_text.py`. B4 4쪽, 페이지 기준 배치, 조건 상자 테두리, 가로 선택지 위치와 네이티브 평행 수식 명령을 확인한다. 실제 한글에서의 렌더링은 별도로 확인해야 한다.
