# Claude와 GPT 사용 설정

1. 설정 → AI API 키에서 사용할 회사의 키를 등록한다. 등록 시 모델 목록만 조회하며 유료 읽기는 하지 않는다.
2. '쪽 읽기 · 글과 수식', '그림 읽기 · 도형과 도표'에서 모델을 각각 고르고 '모델 저장'을 누른다.
3. 두 단계를 모두 GPT로 선택하면 GPT 키만 필요하다. Claude와 GPT를 섞어 선택하면 두 회사의 키가 모두 필요하다.
4. 같은 시험지 한 쪽으로 문항 누락, 수식, 도형 문자·각도·평행 표시를 원본과 비교한다. 모델을 바꾸어도 품질이 같다고 보장하지 않는다.

키와 모델은 현재 브라우저에 연결된다. 다른 브라우저에서는 다시 등록한다. 키는 서버에서 암호화해 보관하며 설정 응답에는 끝 네 자리만 표시한다. GPT 키 삭제는 기존 Claude 키에 영향을 주지 않는다.

월별 사용 요금은 Claude, GPT, 합계를 선택해 확인한다. 표시 금액은 프로그램에서 기록한 추정치이며 실제 청구는 해당 API 계정에서 확인한다.

## 운영

- Next.js 서버는 선택한 모델에 맞는 키만 조회한다.
- Claude 키는 기존 device 행, GPT 키는 sha256("exam-provider:openai:" + device) 행을 사용한다. 모델 설정은 기존 device 행에 유지한다.
- DB 구조 변경 없음. exam-gateway에 GPT 모델과 일반 OpenAI 키 형식 허용을 추가해야 한다.
- GPT는 네이티브 /v1/responses 스트리밍, store:false, 기본 처리 등급을 사용한다.
- 유료 호출 없는 검사: node scripts/run-ts.mjs scripts/check_openai.ts
