# 그림이 많은 시험지와 읽기 결과 복구

- 모든 쪽과 그림 읽기가 끝나면 읽은 결과를 먼저 보관한다. 4MB씩 나눈 비공개 파일을 모두 올린 뒤 문서의 `exam_json`에 조각 목록을 기록한다. 조각 하나라도 실패하면 이전 목록은 유지한다.
- 이 화면에 읽은 결과가 남아 있으면 즉시 다시 만들 수 있다. 보관까지 완료된 읽기 결과는 보관함에서 다시 만들 수 있다. 두 경우 모두 AI를 다시 부르지 않는다.
- 자료 비교 후 출력할 그림도 나누어 보관하고, Python 함수에는 짧은 조각 목록만 보낸다. 함수는 같은 문서의 경로만 받아 저장 창구에서 내려받고, 한글 파일 하나를 보관함에 올린 다음 경로만 응답한다. 요청과 응답의 4.5MB 제한에 큰 파일을 직접 싣지 않는다.
- 저장 창구가 발급한 같은 프로젝트·버킷의 HTTPS 주소만 사용하고 리디렉션을 거절한다. 서명 주소나 API 키를 오류 상세에 기록하지 않는다.
- 현재 한 번에 저장하는 읽기 결과는 최대 96MB(4MB × 24조각), 한글 결과 파일은 최대 49MB다. 한도를 넘거나 파일 전송에 실패하면 이 화면에 남은 읽기 결과로 다시 시도할 수 있다.
- 부분 쪽 읽기 중에 멈추면 아직 전체 읽기 결과가 만들어지지 않아 보관함 복구가 보장되지 않는다. 이전 버전에서 저장되지 않은 읽기 결과도 복구할 수 없다.
- 중간 조각은 문서와 함께 비공개 보관되며, 보관함에서 해당 문서를 삭제할 때 함께 삭제된다.

검사: `node scripts/run-ts.mjs scripts/check_exam_storage.ts`, `python scripts/check_staged_hwpx.py`, 그리고 로컬 시험 서버에서 `python scripts/check_large_conversion.py`. 마지막 검사는 6쪽·그림 30개의 가상 데이터를 사용하고 AI를 부르지 않는다.
