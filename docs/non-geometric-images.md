# 도형 외 자료 재작성

새 변환은 그림 영역을 기하도형, 표, 지도, 통계 그래프, 삽화, 사진으로 분류한다. 기하도형은 기존 수학 엔진을 쓰고, 표·지도·안내도·삽화는 별도의 Claude 판독 지시문으로 안전한 선·타원·글자·표 명령을 받는다. 기존 설정의 그림 모델과 API 키를 사용하며 그림 판독 요금으로 기록한다. 사진으로 인식된 영역은 추가 AI 판독 없이 원본을 사용한다.

명령은 좌표 범위, 색상 형식, 필수 표기, 표의 행열·병합 겹침과 개체 수를 검사한다. 임의 SVG·HTML·JavaScript는 받지 않는다. 실패하면 오류 내용을 돌려보내 최대 한 번 고쳐 받고, 끝내 실패하면 경고와 함께 원본을 보존한다. 이 검사는 문항 의미와 재작성 정확성을 자동으로 증명하지는 않는다.

한글 파일 생성 전 원본과 재작성 결과를 나란히 보여 준다. 자료마다 재작성/원본을 선택하고, 원본을 쓰는 경우 밝기와 ±5도 기울기를 조절할 수 있다. 회전 후에는 모서리가 잘리지 않게 전체를 포함한다. 확인 뒤 한글 파일을 생성하므로 원본 자료로 복구할 때 재차 AI를 부르지 않는다.

원본 배치 HWPX에서는 재작성 자료를 각각 편집 가능한 선·다각형·타원·글자 상자·병합 표로 출력한다. 미리보기 PNG와 명령, 원본 이미지를 보관하며, native 출력이 실패하면 원본으로 복구하고 알린다. 사진과 원본 사용을 선택한 자료는 PNG로 넣는다. 학교 양식의 이전 출력 경로는 PNG로 출력한다.

검사: `node scripts/run-ts.mjs scripts/check_graphics.ts`, `python scripts/check_graphic_hwpx.py`에서 명령 검사, 사진 분류, 필수 글자 누락, 원본 복구, 편집 가능한 선/글자/병합 표를 확인한다. 실제 AI가 복잡한 지도와 삽화를 얼마나 정확히 판독하는지는 원본 비교 화면에서 확인해야 한다.
