- 요금이 드는 서비스, 저장 방식처럼 결정이 필요한 부분은 혼자 정하지 말고, 선택지를 짧게 설명한 뒤 나에게 물어봐.

## 1. 만들 것

시험지 사진이나 PDF를 올리면 글, 수식, 그림, 그래프까지 학교 시험지와 같은 양식의 한글 파일(.hwpx)로 만들어 주는 웹 프로그램.

흐름은 이렇게 된다.

1. 시험지 사진(여러 장)이나 PDF를 올린다.
2. AI가 머리 표 내용, 문제 번호와 배점, 문제 글, 선택지 ①~⑤, 수식, 그림을 읽는다.
3. 확인 화면에서 내가 보고 고친다.
4. 학교 양식 틀에 채워서 한글 파일로 내려받는다.

## 2. 꼭 지킬 규칙

그림

- 그림은 SVG로 그리지 않는다. 원본 사진을 잘라서 결과물에 붙이지도 않는다. 원본 사진은 확인 화면에서 비교할 때만 쓴다.
- 그림은 AI가 "그림 명령"(JSON)을 쓰고, JSXGraph가 캔버스(canvas) 방식으로 그린 뒤 PNG로 저장해서 한글 파일에 넣는다.
- 문제 조건으로 정해지는 점(이등분선이 만나는 점, 수선의 발, 원과 직선이 만나는 점 등)은 좌표를 짐작하지 말고 그림 도구가 계산하게 한다.
- 학생이 연필로 쓴 풀이, 채점 표시, 빨간 펜, 낙서는 넣지 않는다. 인쇄된 것만 옮긴다.

글과 수식

- 문제 글과 선택지는 한글에서 고칠 수 있는 진짜 글자로 넣는다.
- 수식(선분 기호, 각, 분수, 루트, 지수 등)은 한글 수식 개체로 넣는다. AI는 수식을 LaTeX로 읽고, 프로그램이 한글 수식 문법으로 바꾼다. 바꾸지 못한 수식은 글자로 넣고 확인 화면에 표시해 둔다.
- 한국어 줄바꿈은 어절 단위로 한다. 낱말이 중간에서 끊기면 안 된다.

화면

- 글꼴은 에스코어드림을 쓴다.
- 화면 문구는 AI가 쓴 것 같지 않은 자연스러운 말투로 쓰고, 이모지는 쓰지 않는다.
- API 키 같은 비밀값은 서버에만 두고 화면 코드에 넣지 않는다.

## 3. 기술 구성

- 웹: Next.js와 TypeScript. 배포는 Vercel.
- 그림: jsxgraph 1.13.3 (npm 설치), renderer는 'canvas'.
- 한글 파일: Python 라이브러리 python-hwpx==6.9.0. 한글 파일은 서버에서 Python으로 만든다. Vercel의 Python 함수로 돌리는 방법을 먼저 시도하고, 안 되면 다른 방법을 설명한 뒤 나에게 물어봐.
- AI 읽기: Anthropic API (이미지 입력). 모델 이름은 환경변수 ANTHROPIC_MODEL로 두고 기본값은 claude-opus-5-5. 키는 환경변수 ANTHROPIC_API_KEY.
- 확인 화면의 수식 미리보기: KaTeX.
- 저장(양식 보관 등)은 6단계에서 Supabase로 한다. 그 전까지는 저장 없이 한 번에 처리하는 구조로 만든다.

## 4. 데이터 구조

### 4-1. 시험지 JSON (AI가 읽은 결과)

```json
{
  "template": "school-A-2026",
  "header": {
    "title": "2026학년도 2학년 수학과 2학기 1차 정기시험",
    "target": "( 2 )학년 전체",
    "date": "실시 일자 : 2026년 10월 7일( 수 ) 2교시"
  },
  "boxes": [
    { "kind": "notice", "lines": ["…유의 사항…"] },
    { "kind": "score", "lines": ["▶선택형 ( 20)문항: 총 ( 80 )점", "…"] }
  ],
  "sections": [
    {
      "title": "선택형",
      "items": [
        {
          "no": 1,
          "points": 4,
          "stem": [
            { "t": "그림과 같이 " },
            { "m": "\\overline{AB}=\\overline{AC}" },
            { "t": "인 이등변삼각형 ABC에서 …" }
          ],
          "figure": { "box": { "page": 1, "x": 0, "y": 0, "w": 0, "h": 0 }, "commands": {} },
          "choices": [[{ "m": "98^{\\circ}" }], [{ "m": "102^{\\circ}" }]],
          "source": { "page": 1, "x": 0, "y": 0, "w": 0, "h": 0 },
          "unsure": ["choices[2]"]
        }
      ]
    }
  ]
}
```

- 글 안의 수식은 조각으로 나눠 담는다. 글은 {"t": "…"}, 수식은 {"m": "LaTeX"}.
- 문항과 그림마다 원본 사진 속 위치(쪽, 사각형)를 담는다. 확인 화면 비교와 다시 읽기에 쓴다.
- AI가 확신이 낮은 부분은 "unsure"에 적는다.

### 4-2. 그림 명령 JSON

단위는 그림마다 정한다. 보통 밑변이 10 안팎이 되게 잡는다. 아래 종류를 지원한다.

점 만들기

- 좌표로 찍기
- 이등변삼각형 꼭짓점 (밑변 두 점, 꼭지각)
- 한 점에서 길이와 방향으로
- 두 직선의 교점 (직선은 두 점, 또는 한 점과 방향으로)
- 각의 이등분선 (바깥각 포함)
- 원과 직선이 만나는 다른 한 점
- 수선의 발, 중점
- 선 위를 움직이는 자유점 (확인 화면에서 끌어서 옮길 수 있음)

그리기 요소

- 선분, 직선·반직선(연장선), 색칠한 다각형, 원, 호
- 각 표시 호 (겹 수 지정), 똑같이 나뉜 각 표시 (•, ×), 직각 표시
- 같은 길이 표시 (눈금 1~3개)
- 길이 표시 점선 호 (볼록한 방향 지정, 글자 자리는 선을 비움)
- 점 이름과 글자 (위치, 크기, 기울임 여부)
- 채운 점
- 좌표축 (O, x, y, 눈금), 함수 그래프 (식과 범위), 보조 점선
- 쌓기나무 (칸별 층수, 그리는 방식: 사선 또는 등각, 면 색)
- 답 칸 격자 (행, 열, 칸 크기, 점선)
- 동그라미 라벨 (글자, 바탕색, 테두리색)

구체적인 예는 "8. 검증용 예시"를 본다.

## 5. 단계

### 1단계: 한글 양식 틀

- samples/exam_p1.jpg의 양식을 그대로 따르는 한글 파일 생성기를 만든다. 들어갈 것: 맨 위 제목 상자, 응시대상과 실시 일자 표, 안내 상자 두 개(유의 사항, 문항 배점 안내), "선택형" 제목 상자, 그 아래 2단 본문과 가운데 세로 구분선, 꼬리말(쪽 번호와 맨 아래 안내 문구).
- 머리 부분은 1단, 본문부터 2단으로 나눈다.
- 1~3번 문제는 사진을 보고 직접 넣은 데이터로 채운다. 그림 자리는 비워 둔다.
- 완료 기준: 내가 한글에서 열어 원본과 나란히 놓고 확인한다.

### 2단계: 그림 엔진

- 그림 명령 JSON을 JSXGraph(canvas)로 그리고 고해상도 PNG(300dpi 이상)로 저장한다.
- "8. 검증용 예시" A~F를 모두 그리는 테스트 페이지를 만든다. 원본 사진을 반투명하게 겹쳐 보는 기능을 넣는다.
- 완료 기준: 내가 테스트 페이지에서 겹쳐 보기로 원본과 맞는지 확인한다.

### 3단계: 합치기

- 1단계 한글 파일에 2단계 PNG 그림과 한글 수식을 넣는다. 그림은 원본처럼 문제 글 아래나 오른쪽에 둔다.
- 완료 기준: 한글에서 열었을 때 1~3번이 그림과 수식까지 들어가 있다.

### 4단계: AI 읽기

- 사진이나 PDF를 올리면 Claude API로 시험지 JSON을 만든다.
- 두 번에 나눠 읽는다. 첫 번째는 쪽 전체에서 머리 표, 문항, 선택지, 수식, 그림 위치를 읽는다. 두 번째는 그림마다 잘라낸 부분을 다시 보내서 그림 명령을 만든다.
- 인쇄된 글씨와 연필 필기를 구분하라고 지시하고, 확신이 낮은 부분은 표시하게 한다.
- 완료 기준: samples 사진으로 만든 JSON이 1~3단계에서 직접 넣은 내용과 거의 같다.

### 5단계: 확인·수정 화면

- 왼쪽에는 원본 쪽, 오른쪽에는 문항 목록을 둔다.
- 문항마다 글, 선택지, 수식(미리보기 포함)을 고칠 수 있게 한다.
- 그림은 미리보기, 원본 겹쳐 보기, 자유점 끌기, 그림 명령 직접 고치기를 할 수 있게 한다.
- 문항마다 "이 문항 다시 읽기" 버튼을 둔다.
- 그림 모드를 고를 수 있게 한다: 문제 조건대로(기본), 원본 모양대로. 원본 모양대로를 위해 AI가 그림 속 점의 대략적인 위치도 함께 읽게 한다.
- "한글 파일 만들기" 버튼을 누르면 내려받는다.

### 6단계: 양식 등록과 배포

- 새 학교 시험지를 올리면 양식(용지 크기, 여백, 머리 표 구성, 단 수, 구분선, 글꼴과 크기, 꼬리말)을 뽑아 이름을 붙여 Supabase에 저장하고, 다음부터 골라 쓰게 한다.
- Vercel에 배포한다.

## 6. 한글 파일에서 확인된 사항 (python-hwpx 6.9.0)

미리 시험해 보고 확인한 내용이야. 같은 시행착오를 반복하지 않게 참고해 줘.

- 시작: `from hwpx import HwpxDocument`, `doc = HwpxDocument.new()`. 길이 단위는 HWPUNIT이고 1mm는 약 283.465.
- 기본 용지는 A4 (59528 x 84186). 바꿀 때는 `doc.page.set_size(width=, height=)`. 학교 시험지는 B4일 수 있으니 양식마다 설정한다.
- 여백: `doc.page.set_margins(left=, right=, top=, bottom=, header=, footer=)`.
- 2단: `doc.page.set_columns(2, separator_type='SOLID', separator_width='0.12 mm', separator_color='#000000', paragraph=p)`. paragraph를 지정하면 그 문단부터 2단이 된다.
- 글자 모양: `cid = doc.styles.ensure_run(font='함초롬바탕', size=10, bold=False, color='#000000')` 후 `p.add_run(글, char_pr_id_ref=cid)`.
- 문단 모양: `doc.styles.apply_paragraph_format(paragraphs=[p], alignment='LEFT', line_spacing_percent=170, spacing_before_pt=4)`.
- 선 없는 칸: `doc.styles.ensure_border_fill(active_borders=[])`. `border_type='NONE'`은 오류가 난다. 선 있는 칸: `ensure_border_fill(border_color='#000000', border_width='0.12 mm')`.
- 표: `t = doc.add_table(행, 열, width=, border_fill_id_ref=)`, `t.set_column_widths([비율…])`, `t.set_cell_border_fill(행, 열, id)`, `t.merge_cells(...)`, 칸 안 문단은 `t.cell(행, 열).paragraphs[0]`.
- 그림: `item = doc.media.add_image(png_bytes, 'png')`로 넣고 `item.id`를 쓴다. 표 칸 안에는 `p.add_picture(item.id, width=, height=, treat_as_char=True)`. 따로 넣을 때는 `doc.add_picture(png_bytes, 'png', width_mm=, height_mm=, align='center')`.
- 수식: `from hwpx.equation.authoring import latex_to_eqedit` 후 `doc.shapes.add_equation(latex_to_eqedit(latex), paragraph=p)`. `\overline{AB}`, `\angle A=38^{\circ}`, `\frac{2}{3}`, `\sqrt{5}`, `x^{2}`는 제대로 바뀌었다. LaTeX 띄어쓰기 기호 `\ `는 오류가 나니, 오류는 잡아서 글자로 대신 넣는다.
- 꼬리말과 쪽 번호: `doc.page.set_footer(...)`, `doc.page.set_page_number(...)`. "(1 / 7)"처럼 전체 쪽 수가 되는지 확인하고, 안 되면 나에게 알려 줘.
- 검사: `doc.validate()`. 대략적인 미리보기는 `hwpx.tools.layout_preview.render_layout_preview(경로).html` (그림은 상자로만 보임).
- 저장한 뒤 한 번 손봐야 하는 것 (zip을 다시 쓸 때 'mimetype'을 맨 앞에, 압축하지 않은 채로 둘 것):
  - header.xml의 `breakNonLatinWord="BREAK_WORD"`를 `"KEEP_WORD"`로 바꾼다. 이래야 한국어가 어절 단위로 줄바꿈된다.
  - 표 칸의 `vertAlign="CENTER"`는 필요한 곳만 `"TOP"`으로 바꾼다.
  - 그림이 들어간 줄은 칸 높이(cellSz height)를 그림 높이에 맞춰 준다.
- 이 작업 환경에는 한글 프로그램이 없어서 실제 모양은 내가 한글에서 열어 확인한다.

## 7. 그림에서 확인된 사항 (JSXGraph 1.13.3)

- `renderer: 'canvas'`로 그리고, 글자는 `display: 'internal'`로 캔버스 안에 그린다.
- 캔버스 글자의 기본 글꼴이 Arial로 고정돼 있다. `JXG.CanvasRenderer.prototype.drawInternalText`를 덮어써서 원하는 글꼴을 쓰고, `measureText`의 실제 높이로 글자를 정확히 가운데 맞춘다.
- 점 이름 글꼴은 교과서처럼 명조 계열(Times 비슷한 무료 글꼴, 예: Liberation Serif)을 쓰고, 변수 x 같은 것은 기울임으로 쓴다. 라벨 동그라미 안 한글은 에스코어드림.
- 캔버스는 화면 크기의 2배로 그려진다. PNG는 보이지 않는 곳에 큰 보드를 따로 그려서 흰 바탕에 합친 뒤 저장한다.
- 다각형의 테두리 선은 다각형과 같은 층(layer 3)에 그려진다. 점선 호가 선 위로 올라오지 않게 층(layer)을 직접 지정한다.
- 점선 모양은 보드마다 `board.renderer.dashArray`로 바꿀 수 있다. 동그란 점선은 `[0, 간격]`과 둥근 선끝으로 만든다.
- 좌표로 만든 선분은 끝점이 보이지 않게 한다 (`point1`, `point2`를 `visible: false`).
- 쌓기나무는 뒤에 있는 것부터 앞에 있는 것 순서로 면을 그린다.
- 원본 겹쳐 보기는 그림 속 같은 점 몇 개를 짝지어 원본 사진 조각의 위치를 맞추고(최소제곱 아핀 변환), 반투명으로 겹친다.

## 8. 검증용 예시

모두 직접 그려서 원본과 맞는 것을 확인한 값이야. 2단계 테스트 페이지에서 똑같이 나와야 한다.

공통 모양: 선 굵기는 밑변의 약 1%, 점 이름 글자 크기는 밑변의 약 15%, 길이 표시 점선은 본선 굵기의 절반 정도.

A. exam_p1.jpg 1번 (이등변삼각형과 점 D)

- B(0, 0), C(11, 0). AB = AC, ∠A = 38°이므로 A(5.5, 15.973).
- D: C가 중심이고 B를 지나는 원이 선분 AB와 다시 만나는 점. D(2.332, 6.772).
- 선분 AB, AC, BC, DC. 점 이름 A(위), B(왼쪽 아래), C(오른쪽), D(왼쪽). "38°"는 꼭지각 안쪽, A에서 삼각형 높이의 약 29% 아래.
- 원본은 꼭지각이 38°보다 조금 넓게 그려져 있어서, 조건대로 그리면 겹쳐 볼 때 DC가 살짝 어긋나는 것이 정상이다.

B. exam_p1.jpg 2번 (두 이등분선의 교점 D)

- B(0, 0), C(9.5, 0). AB = AC, ∠A = 56°이므로 A(4.75, 8.933).
- E: BC를 C 쪽으로 늘인 선 위의 자유점, 처음 위치는 C에서 3.8. 밑선은 E보다 1.73 더 길게 긋는다.
- D: ∠B의 이등분선과 ∠ACE의 이등분선이 만나는 점. D(14.868, 8.933). ∠D = 28°.
- 선분 AB, AC, BD, CD, 밑선. B의 나뉜 두 각에 •, C 바깥각의 나뉜 두 각에 ×, D에 작은 각 호, E에 채운 점. "56°"는 꼭지각 안쪽.
- 원본과 거의 그대로 겹친다.

C. exam_p1.jpg 3번 (삼각형 ABE, 수선 AC)

- C(0, 0), A(0, 9.4) (AC = 8을 9.4로 그림), E(7.05, 0) (CE = 6), B(-16.281, 0) (∠B = 30°).
- D: 선분 AB 위에서 ∠ADC = 60°인 점. D(-8.141, 4.7)로 AB의 중점과 같다.
- 선분 AB, AE, AC, DC, 밑선(E보다 0.9 더). C에 직각 표시(E 쪽), B에 30° 호, D에 60° 호(∠ADC).
- 길이 표시 점선 호: BD에 기울인 x, AC에 8(E 쪽으로 볼록), AE에 10(바깥쪽), CE에 6(아래쪽). 글자 자리와 점 이름 자리에서는 점선을 비운다.
- 원본은 CE가 조금 길게 그려져 있어서 겹쳐 보면 E 쪽이 살짝 어긋나는 것이 정상이다.

D. cubes_problem4.png (쌓기나무 11개, 등각 그림)

- 칸 c는 앞에서 볼 때 왼쪽에서 오른쪽, 줄 r은 앞에서 뒤. 층수: (0,1)=1, (1,1)=1, (2,1)=1, (1,0)=1, (2,0)=1, (2,2)=2, (2,3)=3, (3,3)=1. 모두 11개.
- 등각 그림: 화면에서 c 방향은 오른쪽 아래(cos30°, -0.5), r 방향은 오른쪽 위(cos30°, 0.5), 높이는 위쪽.
- 면 색: 윗면 #EAD6AE, 앞면 #DFC69A, 옆면 #C9AC82, 모서리 #4B3E31.
- 라벨: 위(연두 동그라미, 아래 화살표), 앞(노랑 동그라미, 왼쪽 아래에서 화살표), 옆(분홍 동그라미, 오른쪽 아래에서 화살표).
- 답 칸: 5 x 5 파란 점선 격자 3개(위, 앞, 옆). 위 격자에는 오른쪽에 '옆', 아래에 '앞' 회색 동그라미.
- 정답 확인용: 앞에서 본 모양 층수는 왼쪽부터 1, 1, 3, 1. 옆에서 본 모양은 앞쪽부터 1, 1, 2, 3.

E. cubes_worksheet.png (쌓기나무 네 모양, 사선 그림)

- 사선 그림: 한 줄 뒤로 갈 때 오른쪽과 위로 각각 0.45칸씩 옮긴다.
- 칸별 층수 h[줄][칸] (0번 줄이 앞줄): [[2,0,0],[3,3,1]], [[0,0,2,1],[1,1,3,1]], [[0,1,0,1,0],[1,2,1,2,1]], [[1,1,1],[3,3,1]]. 개수는 9, 9, 9, 10.
- 면 색: 윗면 #E2BE6C, 앞면 #C88F39, 옆면 #9E5E1E, 모서리 #6E4518.

F. rect_p.jpg (직사각형 ABCD와 점 P)

- B(0, 0), C(12, 0), D(12, 6), A(0, 6). P는 선분 BC 위 자유점, B에서 7.2.
- 삼각형 ABP를 #E8EBC3로 칠하고, 선분 AP를 긋는다.
- 길이 표시: AD 위에 "12 cm", AB 왼쪽에 "6 cm". 회색 동그란 점선 호(반타원 모양)이고 글자 자리는 비운다.
